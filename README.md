# CUL-CYB371-STUDENT-DATABASE
A fictional student dataset created  using python for data mining and data warehousing

ABOUT
This project generates and explores a made-up student database. No real student information is used. It was built for practice with data mining and data warehousing in python.

Contents
READMDE.md: this file
database.ipynb: Jupyter Notebook that creates and explores the dataset

DATASET
The dataset contains fictional student records  .EXample fields student_id, department, level, attendance percentage,average examination score

HOW TO RUN
*clone the repository
*install the requirements(pip install jupyter pandas)
*start Jupyter and open the notebook
*run the cells from top to bottom
